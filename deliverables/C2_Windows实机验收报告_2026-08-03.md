## 1. 测试结论

**结论：通过。**

本结论限定于 C2 Windows 微信实机范围：private 会话准入、消息读取、图片理解、角色与顺序、V3 入库、跨轮去重、首屏短码自动发现、多目标串行和停止监听。

AI 自动回复、Brain、`chat_reply` 发送和 C3 不在本轮验收范围，按现场要求不执行，不计入通过条件。

## 2. 测试范围

- 有效短码 private 会话首屏识别和直接定位。
- 首屏扫描结果自动绑定并进入 `read-targets`，不依赖测试人员预先指定短码。
- 多个短码连续处理时的 UI 锁、会话隔离和串行切换。
- customer/self 文字角色及画面顺序入库。
- self/sales 侧图片识别、真实 Vision、V3 入库和物理图片唯一性。
- 重复扫描不重复识图、不新增图片事件。
- 停止监听后不再定向定位、读取、识图或入库。
- private/group/unknown 准入、customer/self 语音等未改功能沿用此前 Windows 实机通过证据，本轮未重复执行。

  `v16.130.0 / 8ee53e1` 的已验收回滚结论。
