## 3. 环境启动方式

### 3.1 后端启动

后端工程目录：`backend/`

```bash
cd backend
cp .env.example .env
docker compose up --build -d
```

健康检查：

```bash
curl http://127.0.0.1:8000/healthz
curl http://127.0.0.1:8000/readyz
```

期望结果：

```json
{"status":"ok"}
```

```json
{"status":"ok","database":"ok"}
```

后端 API 地址：

```text
http://127.0.0.1:8000/api
```

如需初始化演示销售数据：

```bash
cd backend
docker compose exec api python scripts/seed_dev.py
```

### 3.2 前端启动

前端工程目录：`frontend/`

```bash
cd frontend
npm install
npm run dev
```

前端访问地址：

```text
http://127.0.0.1:5173/
```

前端环境变量参考：

```text
VITE_API_BASE_URL=http://127.0.0.1:8000/api
VITE_OPERATOR_ID=00000000-0000-0000-0000-000000000001
VITE_OPERATOR_NAME=Ops Tester
VITE_OPERATOR_ROLE=admin
```

说明：Vite 前端依赖后端接口。测试前必须先确认后端 `/readyz` 正常，否则页面可能进入 loading/error/空数据状态，影响功能和视觉判断。


## 5. 测试范围

P0 测试范围：

- 人工新增客户线索
- 手机号强去重
- 重复手机号 `409 / LEAD_PHONE_DUPLICATED`
- 重复录入记录和备注追加
- 销售轮询自动分配
- 销售停用后分配失败
- 恢复销售后重新分配
- 线索列表、搜索、筛选、分页
- 线索详情
- 标记无效 / 恢复有效
- 批量标记无效
- 手机号明文查看和操作审计
- 选中线索导出，手机号脱敏
- 销售管理列表和轮询开关
- 操作日志独立页面
- 后端 `trace_id/request_id` 错误链路

不包含范围：

- 抖音 API 自动同步
- 飞鱼 / 巨量线索 Webhook
- 正式 Excel/CSV 批量导入
- RPA 加微信
- Worker 执行台
- AI 自动回复
- 飞书接管通知
- 销售登录后台
- 正式鉴权
- 生产环境部署
