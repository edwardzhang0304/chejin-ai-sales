# C2 V16.94 Windows 实机回归说明

> 状态：已撤回，由 V16.95 替代。代码审计发现 V16.94 在复用业务截图时绕过了标题栏 ROI 补充 OCR，存在整帧 OCR 漏标题后错误阻断的风险，请勿继续回归此包。

## 本版目标

V16.94 只合并“页面没有变化”时的重复截图/OCR，不删除任何点击后、转写后、滚动后的新截图。

1. 读消息的同一帧先确认目标会话，再解析消息。
2. 语音转写前的同一帧先确认目标会话，再识别当屏语音。
3. 语音转写后不再单独启动一次 `locate_chat(current)`，最终读消息的新截图同时完成复核。
4. 状态目标的首屏匹配和点击由同一个 sidecar 新鲜帧完成，不使用 Worker 旧坐标。
5. 后台 status OCR 默认 20 秒刷新，UI 锁期间不与 C2 OCR 并发。

## 重点验证

1. 首屏有目标时直接点击唯一目标，不应无故打开搜索框。
2. 首屏无目标时才允许短码搜索；多候选时必须阻断，不得猜测点击。
3. customer/self 双侧语音均要转写、角色正确、正文完整。
4. 每转写一条后必须从新截图重新定位，不得使用旧 y 坐标。
5. 不应重复右键已转写语音，不应点头像，不应使用 ESC 导致微信窗口消失。
6. 纯文字不得被当作语音；语音展开文字不得再作为独立 text 入库。
7. 对比 V16.92/V16.93 的 `target_chat_locating`、`initial_message_read`、`voice_transcribe`和总耗时。
