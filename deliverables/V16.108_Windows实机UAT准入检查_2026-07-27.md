安装包。manifest 明确标记工作区不干净、非正式发布且未执行预检；包内没有
`车金Worker客户端.exe`。此外，manifest 声明的合同 SHA256 与 ZIP 内实际合同

本次 UAT 在环境门禁阶段终止。C1、C2、C3、任务中心、召回和异常恢复均未开始执行。

## 四、开发与打包整改要求

1. 在干净 Git 工作区固定最终提交，确保 `git status --short` 为空。
2. 在 Windows 使用 `scripts\build-windows.ps1` 正式构建，不得使用
   `-DevelopmentBuild`。
3. 产出包含 `车金Worker客户端.exe` 的正式安装目录或正式安装包。
4. manifest 必须满足：
   - `git_dirty=false`
   - `formal_release=true`
   - `tests_status=passed`
   - `preflight_status=passed`
5. 执行 `scripts\validate-package.ps1` 并保留报告。
6. manifest 中合同 SHA256 必须与安装包内实际合同文件完全一致。
7. 提供 EXE SHA256、合同 SHA256、安装包 SHA256、Worker commit、
   OmniAuto commit 和 OmniAuto tree SHA256。
8. 在测试 Windows 上执行真实模式预检，确认微信登录、Worker 绑定、后端连接及
   `CUSTOMER_IMAGE_UNDERSTANDING_API_KEY` 或等价 Vision Key 已配置。
9. 保留真实 Brain 配置，不得切换 mock；正式 UAT 前先执行一次无微信副作用的
   Vision/Brain 连通性检查。

列出的全部未执行项目重新开始。
