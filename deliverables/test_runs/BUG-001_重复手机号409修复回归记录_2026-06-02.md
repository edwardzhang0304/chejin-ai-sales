# BUG-001 重复手机号 409 修复回归记录

日期：2026-06-02

## 结论

已修复并通过真实接口回归。重复手机号保存接口现在返回 `409 Conflict / LEAD_PHONE_DUPLICATED`，不再返回 `500 Internal Server Error`。

## 修复点

- 文件：`backend/app/api/response.py`
- 原因：`DuplicateLeadError.data` 中包含 `datetime`，`JSONResponse` 直接序列化导致 `TypeError: Object of type datetime is not JSON serializable`。
- 处理：错误响应统一使用 `fastapi.encoders.jsonable_encoder` 转换后再交给 `JSONResponse`。

## 回归方式

1. 将修复同步到当前运行中的 Docker API 容器。
2. 重启 `api` 容器。
3. 使用新手机号新增线索。
4. 使用同一手机号再次新增线索。

## 回归结果

重复新增接口返回：

```http
HTTP/1.1 409 Conflict
```

响应关键字段：

```json
{
  "code": "LEAD_PHONE_DUPLICATED",
  "data": {
    "created": false,
    "duplicate_count": 1,
    "duplicate_dates": ["2026-06-02"],
    "note_appended": true
  }
}
```

其中 `duplicate_lead.created_at` 和 `duplicate_lead.updated_at` 均已返回 ISO 字符串。
