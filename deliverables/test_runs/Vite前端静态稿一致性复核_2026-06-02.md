# Vite 前端静态稿一致性复核

> 日期：2026-06-02  
> 复核口径：以 `website/ops-admin.html` / `website/ops-admin.css` 为基准，按桌面 1440x1000 视口对比核心盒模型和首屏视觉。  
> 结论：有条件通过。线索页桌面核心布局尺寸已与静态稿对齐；全页面像素级完全一致仍不通过，剩余差异见下方。

## 本轮修正

| 项目 | 修正前问题 | 本轮处理 |
|---|---|---|
| 列表面板结构 | Vite 缺少静态稿 `panel-header`，筛选区混入“重试/刷新”按钮 | 补齐列表标题/说明/重新分配入口，移除筛选区多余按钮 |
| 筛选卡 | 网格结构与静态稿不一致 | 改为 `260px 180px 180px`，`728x86`，`gap=28px` |
| 批量操作 | 重新分配按钮位置不符合静态稿 | 批量区仅保留“标记无效 / 导出”，重新分配移到面板头部 |
| 表格 | 表格容器、列宽、状态标签类名与静态稿不一致 | 改为 `table-card 728x320`，补齐 9 列固定宽度和 `.status` 样式 |
| 分页 | 分页高度和结构不符合静态稿 | 改为 `pagination-row 172px`，补齐总数、页大小、页码结构 |
| 页面节奏 | Vite 工作区 `y=231`，静态稿 `y=240` | 改为页头 `margin-bottom=5px`、指标卡 `height=110px`、指标区 `margin-bottom=24px` |

## 仍未完全一致

| 差异 | 当前表现 | 影响 | 建议 |
|---|---|---|---|
| 数据内容不同 | 静态稿显示示例数据，Vite 显示真实后端种子数据 | 像素对比无法完全一致 | 若要求截图逐像素一致，需要提供固定 mock 数据或测试环境 seed 与静态稿一致 |
| 选中态不同 | 静态稿默认“已选 2 条”，Vite 默认“已选 0 条” | 批量行和表格选中背景不同 | 明确是否要求默认选中两条；如要求，前端需初始化选中态 |
| 详情区内容状态不同 | 静态稿详情为“王先生”示例，Vite 为真实第一条线索 | 右侧文字和局部高度观感不同 | 需要统一验收数据或将静态稿更新为真实状态 |
| 浏览器自动化脚本 | 原 Playwright 脚本 Chrome 启动 180s 超时 | 影响自动化截图复跑 | 本轮改用 Codex Browser 完成截图；建议后续修复脚本运行环境 |
