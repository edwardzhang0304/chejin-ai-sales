## 8. 缺陷记录

### BUG-FE-20260603-001：移动端线索页页面级横向溢出

| 字段 | 内容 |
|---|---|
| 严重等级 | P1 |
| 模块 | Vite 前端 / 线索管理 / 移动端布局 |
| 影响范围 | 390px 移动端视口，线索页出现整体横向滚动 |
| 复现步骤 | 1. 设置视口为 390x844。2. 打开 `http://127.0.0.1:5173/`。3. 点击“线索管理”。4. 检查页面横向滚动宽度。 |
| 实际结果 | `bodyScrollWidth=1136`，`documentScrollWidth=1136`，大于 `viewportWidth=390`，页面级横向溢出 |
| 预期结果 | 页面整体宽度不超过视口；表格如需横向滚动，应限制在表格容器内部 |
| 影响 | 移动端访问线索页时需横向滚动整个页面，影响兼容性验收 |
| 初步定位 | `list-region/table-card/filter-card/detail-drawer` 等桌面固定宽度在小屏下未完全响应式收敛 |
| 证据 | `deliverables/test_runs/p0_full_regression_2026-06-03/mobile_overflow_audit.json`、`07-mobile-leads.png` |
