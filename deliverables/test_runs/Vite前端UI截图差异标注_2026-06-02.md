# Vite 前端 UI 截图差异标注

> 执行日期：2026-06-02  
> 对照对象：`frontend/` Vite 前端 vs `website/ops-admin.html` 静态设计稿  
> 复核方式：Playwright 截图 + DOM/CSS 指标抽取 + 人工截图复核  

## 1. 结论

**结论：主视觉、P0 功能布局和静态稿关键差异已基本收口，未发现阻断验收的视觉问题。**

Vite 版已经对齐静态稿的关键设计 token：蓝色侧栏、灰色页面底、白色面板、8px 圆角、状态色、苹果字体体系、线索指标卡、列表/详情双栏、销售卡片。移动端表现优于静态稿：Vite 页面无页面级横向溢出，表格在容器内横向滚动；静态稿移动端存在页面级横向溢出。
