# C2 V16.88 Windows 实机回归说明

## 一、回归版本

```text
客户端：V16.88
压缩包：chejin-worker-client-20260718-v16.88.zip
SHA256：b48da4af59575a9a140200d756eae8bcc47a36f203bb33f4298cc710e5e4bd22
后端：http://192.168.2.106:8000/api
```

本版本是 Windows 实机回归候选，尚未取得 C2 最终通过结论。

## 二、本次根因

V16.87 的 V3 只统一了跨层数据合同，OmniAuto 底层仍有 parser、原始 OCR 时长、左右气泡像素和行内按钮等多套候选规则。它们会各自选目标，再以“谁更靠下”竞争。

实机日志证明：下面已经转写完成的 self `6"` 被视觉规则再次选中；关闭其右键菜单后，菜单验证又看到了页面顶部另一条语音旁的行内“转文字”，误判为菜单未关闭，流程提前结束，因此顶部 customer 语音没有处理。转写正文末尾“来。”还因 OCR 框重叠 1px 被拆成独立文字，导致 voice 正文缺字。

## 三、V16.88 底层改动

1. OmniAuto 新增唯一语音观察入口。parser、OCR 时长、气泡像素、同行头像和行内按钮只作为证据，先按同一气泡区域、同一角色、同时长合并，再由一个选择器决定动作。
2. parser 已确认转写完成的语音是最终事实，原始 OCR 或像素规则不得把它降级成未转写，也不得再次右键。
3. 左右两侧视觉检测返回当前屏幕全部候选，不再各自只返回最下面一条；统一观察按从下到上处理，并使用 processed/exclusion 集合跳过已完成 anchor。
4. 行内“转文字”只能附着到已选中的待转写语音，不能独立决定点击哪条语音。
5. 右键菜单关闭只检查原菜单矩形，不再被页面其他语音旁的“转文字”干扰；关闭兜底不使用 Esc，也不点击聊天区头像或气泡。
6. 已进入同一语音转写组的短尾行允许小幅 OCR 框重叠，`什么时候过` + `来。` 必须合并成一条完整 voice 正文。
7. 语音 flow 不主动滚动；转写后被顶出当前屏幕的语音本轮不追踪。

## 四、本轮重点测试

1. 当前屏幕同时准备至少两条 customer 语音和一条 self/sales 语音，最好包含上下均有语音、相同时长和一条较长转写正文。
2. 确认处理顺序为当前屏幕从下到上；每条只右键一次，已经出现转写正文的语音不得再次右键。
3. 确认顶部 customer 语音不会因下面语音菜单关闭而漏掉。
4. 确认左右角色：左头像同行语音为 `customer`，右头像同行语音为 `self`；转写文字继承所属语音角色。
5. 确认多行转写正文完整，特别检查最后一个短词或单字不得被拆成普通 text。
6. 确认不点头像、不出现“拍一拍”、不使用 Esc、不隐藏微信窗口、不主动滚动。
7. 确认同一语音只产生一条 V3 voice 事件，不产生同文 text，不跨轮重复入库。
8. 停止监听后目标不得继续定位、读取、转写或入库；常驻首屏扫描仍允许继续。

## 五、通过标准

- 当前屏幕全部可见未转写语音逐条得到明确成功或失败结果，成功项正文完整并按 voice 上报。
- 已转写语音不重复右键；顶部 customer 与右侧 self 均能覆盖。
- `sender_role`、`message_type`、anchor 和正文在 OmniAuto、Worker、后端三层一致。
- 不出现头像菜单、窗口隐藏、主动滚动、菜单残留或 OCR 菜单文字入库。
- `messages/ingest` 返回 200，同一语音不重复入库。

## 六、Windows 启动命令

以下命令可整段粘贴到 PowerShell：

```powershell
cd $env:USERPROFILE\Desktop
Expand-Archive -Force .\chejin-worker-client-20260718-v16.88.zip .\chejin-worker-client-20260718-v16.88
cd .\chejin-worker-client-20260718-v16.88\worker-client
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
$env:CHEJIN_API_BASE_URL="http://192.168.2.106:8000/api"
$env:CHEJIN_RPA_MODE="real"
$env:CHEJIN_C2_VOICE_TRANSCRIBE_MAX_DURATION_SECONDS="240"
.\.venv\Scripts\python.exe -m chejin_worker_client.main
```
