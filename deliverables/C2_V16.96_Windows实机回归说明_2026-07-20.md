# C2 V16.96 Windows 实机回归说明

## 本版修改

1. C2 本期只准入带有效短码的 private 单聊。
2. 复用点击会话后的现有顶部标题 OCR，不新增点击、截图或 OCR。
3. 在删除标题末尾括号数字之前识别 `(5)`、`（5）` 等群成员数量。
4. `group` 和 `unknown` 在读取文字、语音、图片及上报前立即阻断。
5. 单聊与群聊同短码时只允许单聊参与唯一性判断；两个单聊同码仍判真实冲突。
6. `conversation_type` 只用于准入，不参与消息 ID、去重键和会话身份。

## 重点验证

1. 带短码普通单聊正常读取。
2. 带短码群聊半角人数后缀 `(5)` 不读取、不转写、不入库。
3. 带短码群聊全角人数后缀 `（5）` 不读取、不转写、不入库。
4. 单聊和群聊使用相同短码时，只允许单聊准入。
5. 两个单聊使用相同短码时，两者都不得读取。
6. 标题 OCR 不完整、人数模糊或证据冲突时按 unknown 阻断。
7. 不带短码的会话不点击、不判断类型、不读取。

重点核对调试证据中的 `raw_title`、`conversation_type`、`conversation_type_reason` 和错误码。
