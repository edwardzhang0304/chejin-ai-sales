## 1. 结论

当前 Vite 新增客户弹窗必须按最终确认稿实现，但不新增业务范围，不接入抖音/RPA/AI/飞书/批量导入。

本期 P0 前端基准口径：

- 主页面以本地静态稿为视觉基准：`website/ops-admin.html`、`website/ops-admin.css`、`website/ops-admin.js`。
- 新增客户弹窗不按当前 `website` 里的“添加联系方式 + 类型下拉”版本。
- 新增客户弹窗以 `deliverables/design_preview/create-lead-modal-final.html` 为最新视觉基准。
- 新增客户弹窗无右上角 `X`，关闭动作由底部 `取消` 按钮承担。
- 新增客户弹窗联系方式固定为 `手机 *`、`微信`、`邮箱` 三项，不再支持添加/删除联系方式行。
- 新增客户弹窗自定义信息支持动态维护，有 `添加字段`，每行由 `字段名称 + 字段内容 + 删除` 组成。

后端 payload 已支持复杂字段：

```ts
type LeadCreatePayload = {
  customer_name: string;
  phones: string[];
  wechats?: string[];
  emails?: string[];
  remark?: string;
  custom_fields?: Record<string, unknown>;
};
```

因此前端可以直接改 UI 和提交结构，不需要后端新增字段。

## 2. 弹窗结构

弹窗标题：

- `新增客户`
- 无右上角关闭按钮。

顶部重复手机号强提示：

- 默认不展示。
- 当重复预查命中，或保存返回 `LEAD_PHONE_DUPLICATED` 时展示。
- 文案：
  - 标题：`该手机号已存在，不能重复新建`
  - 说明：`已重复录入 {duplicate_count} 次，本次备注将追加到原线索。`
  - 操作：`查看原线索`

基础信息：

- `客户名称 *`
- 输入框，必填。

联系方式：

- `手机 *`
  - 固定 1 个输入框。
  - 必填。
- `微信`
  - 固定 1 个输入框。
  - 选填。
- `邮箱`
  - 选填。
  - 固定 1 个输入框。

不再有：

- `添加手机号`
- `添加微信`
- `添加邮箱`
- `删除`

补充信息：

- `自定义信息`
  - 选填。
  - 支持动态维护。
  - 有 `添加字段`。
  - 每一行是 `字段名称 + 字段内容 + 删除`。
  - 提交时过滤空字段，并组装为 `custom_fields`。
- `备注`
  - textarea。
  - 示例：`客户说预算 10 万左右，想看 SUV，周末方便到店。`

底部按钮：

- `取消`
- `保存`
- `保存并继续新增`

## 3. 交互规则

打开弹窗：

- 清空上一次表单状态。
- 固定展示 `手机 *`、`微信`、`邮箱` 三个联系方式输入框。
- 自定义信息默认展示若干空字段行，可添加或删除。
- 重复提示默认隐藏。

保存：

- 校验客户名称非空。
- 校验手机号非空。
- 去掉空微信、空邮箱、空自定义信息。
- 调用 `createLead(payload)`。
- 成功后关闭弹窗，刷新线索列表。

保存并继续新增：

- 调用同一个 `createLead(payload)`。
- 成功后不关闭弹窗。
- 清空表单，保留固定结构。
- 自定义信息重置为空字段行。
- 展示成功提示：`已保存，可继续新增客户。`

重复手机号：

- 必做：保存返回 `LEAD_PHONE_DUPLICATED` 后，弹窗不关闭，展示顶部强提示。
- 可选增强：手机号输入完成后调用 `POST /api/leads/duplicate-preview` 做预提示。

查看原线索：

- 如果有 `duplicateData.duplicate_lead.id`：
  - 关闭弹窗。
  - 打开对应线索详情。
- 如果当前前端暂时不方便定位详情，可先做为 disabled 按钮或点击后 toast：`请在列表中搜索该手机号查看原线索。`

## 4. 接口补充

当前 `frontend/src/features/leads/api.ts` 只有 `createLead`，可以新增：

```ts
export type DuplicatePreviewItem = {
  phone_masked: string;
  has_active_duplicate: boolean;
  duplicated: boolean;
  lead_id: string | null;
  customer_name: string | null;
  sales_name: string | null;
  duplicate_count: number;
  duplicate_lead: DuplicateLeadErrorData["duplicate_lead"] | null;
};

export function duplicatePreview(phones: string[]) {
  return request<{ items: DuplicatePreviewItem[] }>("/leads/duplicate-preview", {
    method: "POST",
    body: { phones },
  });
}
```

如果今天时间紧，`duplicatePreview` 可以先不做，不影响 P0 功能验收。保存 409 后强提示必须做。

## 6. 当前最终稿差异口径

当前最终稿不再要求：

- 多手机号。
- 多微信。
- 多邮箱。
- 添加/删除联系方式。
- 右上角 `X` 关闭按钮。

当前最终稿仍要求：

- 固定 `手机 *`、`微信`、`邮箱` 三项联系方式。
- 自定义信息支持动态添加字段和删除字段。
- 自定义字段由 `字段名称 + 字段内容` 组成。
- 底部保留 `取消 / 保存 / 保存并继续新增`。
- 重复手机号在弹窗顶部强提示。
- 提供 `查看原线索` 入口。
