# C2 群聊与侧栏 OCR Windows 专项回归结果

## 1. 测试结论

**结论：按本轮约定范围通过。**

本轮确认：当前已打开的 `CJTEST01 (6)` 群聊能够直接阻断，不再打开搜索框，不读取、不入库；当前真实侧栏没有产生数字/时间伪会话或重复短码候选；`CJWIN01` private 会话仍能首屏直接点击。

以下内容未纳入本轮通过结论：人工构造数字角标 `2` 的污染场景、全角 `CJTEST01（6）` 的独立 Windows 样本、非首屏短码搜索。前两项受现场数据限制，第三项由产品明确取消本轮测试。

## 6. 遗留风险

1. 本轮真实侧栏没有可控数字角标 `2`，不能替代此前构造坐标场景的边界回归。
2. Windows 现场显示的是半角 `CJTEST01 (6)`；全角 `CJTEST01（6）` 需由自动化测试或另一真实样本覆盖。
3. 客户端显示版本未取得，报告暂记为【待确认】。
