# P1a 车金 Worker 客户端 Windows 单应用 UI 草图说明

日期：2026-06-11

## 一句话结论

车金 Worker 客户端是商家侧 Windows 本地自动化执行终端。对商家只交付一个“车金 Worker 客户端”，OmniAuto 作为客户端内置 RPA 执行组件，不作为独立产品、独立应用或独立操作入口出现。正常主流程以 RPA 自动执行 add_friend 任务为核心；人工传值只保留为调试/兜底能力，不出现在正常销售操作主流程。

## 设计范围

本轮请设计：

- Worker 首次绑定页
- Worker 首页
- 当前任务执行页
- 任务链路可视化
- 首页最近错误摘要
- 设置页本机执行日志
- 调试/兜底入口
- 连接异常、自动化组件不可用、微信不可控、绑定失效等状态

本轮不设计：

- Mac Worker
- 运营后台任务中心
- AI 回复
- 飞书通知
- 召回
- 客户通过好友申请后的会话读取和消息发送主链路

## 视觉方向

- 形态参考附件中的“微信桌面客户端旁边的小工作台”，但不复用对方品牌、Logo、命名或视觉资产。
- 当前项目统一用 `车金 Worker 客户端`、`Worker 工作台`、`车金` 口径。
- 页面是 Windows 本地执行终端，不是运营后台。
- 页面不要把 OmniAuto 画成第二个应用、第二个品牌、第二套状态面板或商家需要单独启动的产品。
- 主按钮强调 `启动`、`暂停`、`查看错误`，不要把人工确认放成主操作。
- 任务链路要让值守人员和运营能看懂当前任务从领取到完成走到了哪一步、卡在哪里、结果是什么。

### 绑定页规则

- `Worker ID` 和 `Worker Token` 必填。
- 绑定成功后进入 Worker 首页。
- 如果 Worker 已绑定其他客户端，提示：`该 Worker 已绑定其他客户端，请联系管理员在后台重置绑定`。
- 后台重置绑定后，旧客户端进入绑定失效状态。

### 当前任务规则

- Worker 启动后自动领取可处理的 `pending add_friend` 任务。
- 领取成功后任务进入 `running`。
- 同一个 Worker 同一时间只允许一个 `running` 任务。
- Worker 端展示完整手机号，供内置 RPA 组件在本机微信中搜索。
- `备注短码` 用于写入好友申请备注或申请说明，具体字段由后端返回。
- 任务链路来自内置 RPA 组件自动上报，不是人工点击步骤。
- 任务链路只展示已经发生或正在发生的节点；未到达的后续步骤不展示。
- 备注短码 / 申请说明必须在发送添加通讯录邀请前写入。

### 成功规则

- 发送好友申请成功后，服务端写入 `completed + result_code=invite_sent`。
- 如果 RPA 判断已是好友，服务端写入 `completed + result_code=already_friend`。
- `invite_sent` 不代表客户已经同意好友申请。
- 成功后如果 Worker 仍处于运行中，自动继续领取下一条任务；如果没有可领取任务，则进入空闲等待。

### 失败规则

- RPA 执行失败后，必须回传 `error_code` 和错误说明。
- 服务端写入 `failed + error_code`。
- 失败原因展示在 Worker 客户端和运营后台任务中心。
- 失败链路只展示已发生节点和失败节点，不展示未到达的后续步骤。
- 失败后是否继续领取下一条任务由 Worker 运行状态和后端策略决定。

## 9. 状态与文案口径

| 状态 | 页面文案 | 说明 |
|---|---|---|
| idle | 空闲 | 已启动但暂无 running 任务 |
| paused | 暂停 | 不领取新任务 |
| running | 运行中 | 正在执行任务 |
| offline | 离线 | 心跳超时或服务端不可达 |
| error | 异常 | 自动化组件、微信或任务执行异常 |

关键文案：

- 使用 `启动 / 暂停`，不要使用 `启动 RPA`。
- 使用 `任务链路` 或 `RPA 执行过程`，不要使用 `人工执行步骤`。
- 使用 `已发送添加通讯录邀请`，不要使用 `加好友成功`。
- 使用 `该结果不代表客户已同意好友申请`。

## 10. 待确认

- `备注短码` 的字段名和生成规则是否由后端统一返回。
- Worker 暂停时，如果当前已有 running 任务，是执行完当前任务后暂停，还是立即停止领取且不中断当前任务。
- RPA 失败后 Worker 是否自动继续领取下一条任务，还是需要等待值守人员确认。
- 调试/兜底模式是否需要权限开关或隐藏入口。
