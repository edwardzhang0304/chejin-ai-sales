## 1. 结论

当前关于抖音线索获取已达成阶段性共识：本期先做人工导入，不做抖音 API 自动接入。

抖音开发者开放平台已审核通过，但 API 接入、企业私信 Webhook、OAuth 授权、巨量引擎/小风车自动同步等能力统一延后到下一期规划。本期重点收敛为线索人工导入、字段映射、去重校验、线索分配和后续跟进流程。

## 4. 本期范围

| 模块 | 内容 | 验收标准 |
|---|---|---|
| 线索人工录入 | 支持运营/管理员手动新增客户线索 | 填写必填项后可成功创建线索 |
| 线索人工导入 | 支持通过 Excel/CSV 导入抖音线索 | 可按模板导入数据，并生成线索记录 |
| 字段映射 | 映射客户姓名、手机号、微信、城市、来源、备注等字段 | 导入后字段展示正确、可查询 |
| 数据校验 | 校验手机号、必填字段、重复线索 | 异常数据有明确失败原因 |
| 去重规则 | 以手机号作为 P0 强去重字段 | 同一手机号不重复创建有效线索 |
| 线索分配 | 支持单条/批量分配给销售 | 分配后线索状态和负责人可见 |
| 导入结果反馈 | 展示成功数、失败数、失败明细 | 运营可定位失败行和失败原因 |

## 6. 线索字段建议

本期人工导入建议优先支持以下字段：

| 字段 | 中文列名 | 是否必填 | 说明 |
|---|---|---:|---|
| name | 客户姓名 | 否 | 真实姓名、昵称或客户称呼 |
| telephone | 手机号 | 是 | P0 强去重字段 |
| weixin | 微信号 | 否 | 微信号、微信昵称或备注号 |
| province_name | 省份 | 否 | 客户所在省份 |
| city_name | 城市 | 否 | 客户所在城市 |
| county_name | 区县 | 否 | 客户所在区县 |
| address | 详细地址 | 否 | 客户补充地址 |
| source | 线索来源 | 是 | 例如：抖音小风车、企业号私信、人工录入 |
| clue_type | 线索类型 | 否 | 可记录表单、私信、小风车等 |
| clue_intention | 意向等级 | 否 | 高/中/低或业务自定义 |
| advertiser_name | 广告主名称 | 否 | 后续对接巨量引擎时保留 |
| promotion_name | 推广计划 | 否 | 后续分析投放效果时保留 |
| create_time_detail | 线索创建时间 | 否 | 抖音侧原始创建时间 |
| remark | 备注 | 否 | 客户需求、车型、预算、跟进说明 |
| tags | 标签 | 否 | 多个标签建议用逗号分隔 |
| external_clue_id | 外部线索ID | 否 | 后续 API 自动同步时用于幂等/追踪 |
