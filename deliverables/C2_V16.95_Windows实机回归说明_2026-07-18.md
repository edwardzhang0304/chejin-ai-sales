# C2 V16.95 Windows 实机回归说明

## 本版修复

V16.94 合并重复截图后，复用了同一张业务截图，也直接复用了整帧 OCR 结果。代码审计发现：整帧 OCR 偶尔漏掉微信顶部会话标题时，旧流程没有再识别标题栏局部区域，可能把正确会话误判为错误会话。

V16.95 调整为：

1. 先使用整帧 OCR 校验当前会话。
2. 整帧已识别标题时直接继续，不增加耗时。
3. 只有整帧漏掉标题时，才对同一张截图的标题栏区域补充 OCR，不重新截图。
4. 标题栏补充 OCR 仍不匹配时，禁止读消息、点击语音和入库。

本版没有修改菜单等待、转写后重新截图、页面变化后重新定位、滚动策略和安全交互；没有新增 ESC，也没有恢复旧坐标点击。

## 重点验证

1. 正确目标且整帧能识别标题时，正常进入读取，不应增加一次标题栏 OCR。
2. 正确目标但整帧漏标题时，应由同一截图的标题栏 ROI 校验后继续，不应重新截图或错误失败。
3. 当前会话不是目标时，必须阻断，不得点击语音、读错消息或入库。
4. customer/self 双侧语音仍应完整转写，角色正确，不重复右键、不点头像、不隐藏微信窗口。
5. 任一点击、转写文字出现或页面位移后仍必须使用新截图，旧坐标不得复用。
6. 对比 V16.94 的定位、读取、语音转写和总耗时，确认可靠性补修没有明显拖慢正常路径。
