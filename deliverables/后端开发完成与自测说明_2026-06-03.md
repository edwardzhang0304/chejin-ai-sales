## 4. 运行环境

后端工程目录：`backend/`

启动方式：

```bash
cd backend
docker compose up --build
```

后台启动方式：

```bash
cd backend
docker compose up --build -d
```

健康检查：

```bash
curl http://localhost:8000/healthz
curl http://localhost:8000/readyz
```

说明：

- `/healthz`：服务存活检查。
- `/readyz`：数据库就绪检查，正式 Docker healthcheck 使用此接口。
- Docker Compose 当前包含 `api` 和 `db` 两个服务。
- API 默认端口：`8000`。
- PostgreSQL 默认端口：`5432`。
- 本地 Docker 镜像已重新 build，包含 `/readyz`、`PYTHONPATH=/app`、CORS、BUG-001 重复手机号 409 修复、导出审计 `target_id` 修复、`trace_id/request_id`、Fernet 联系方式加密、Alembic 迁移脚本。
