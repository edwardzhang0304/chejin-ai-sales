# C2 V16.95 Windows 实机完整回归测试报告

## 1. 测试结论

**结论：通过。V16.95 可作为 C2 当前准入版本，允许进入 C3。**

本轮完成了 V16.95 Windows 真实微信主链路、OCR 提速、customer/self 双侧语音真实转写、V3 入库、去重和停止监听回归。首屏目标直接点击，未打开搜索框；3 条语音全部真实转写并正确入库为 `customer voice=2`、`self voice=1`，转写内容经现场确认与原语音一致。

性能方面，`target_chat_locating` 由 V16.92 的 67.67 秒降至 8.13 秒，缩短 59.54 秒，改善约 88.0%；授权到首次进入消息读取由 77.31 秒降至 21.33 秒，缩短 55.98 秒，改善约 72.4%。

本轮未发现新增 P0/P1 缺陷。Windows 现场未出现重复右键、点头像、ESC、微信窗口消失、主动上滚或错误搜索。

V16.95 聚焦自动化执行结果：4 项通过，耗时 0.023 秒。

1. 整帧漏标题时，同一 messages 截图执行一次标题栏 ROI OCR 并继续，不重新截图。
2. 整帧已识别标题时，不执行额外标题 ROI OCR。
3. 同帧标题 ROI 识别为错误会话时返回 `target_title_not_confirmed`。
4. voice before 确认为错误目标时阻断菜单点击。
