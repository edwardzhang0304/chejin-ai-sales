# C2 V16.97 Windows 实机回归说明

## 本版修改

V16.96 已能从聊天窗口顶部标题判断当前会话是群聊，但 Worker 收到群聊阻断结果后仍会错误进入短码搜索。V16.97 将以下结果设为本轮定位终止态：

- `C2_GROUP_CHAT_NOT_ALLOWED`
- `C2_CONVERSATION_TYPE_UNKNOWN`
- `C2_VISIBLE_TARGET_AMBIGUOUS`

命中以上任一结果后，本轮立即结束，不再打开搜索框，不读取消息，不执行语音转文字，也不上报消息。

普通的“首屏没有找到目标”仍保留短码搜索兜底。本版没有修改搜索结果解析、OCR、坐标或点击规则。

## 重点验证

1. 群聊已经在首屏并被打开，顶部标题为 `CJTEST01 (6)` 或 `CJTEST01（6）` 时，不得打开搜索框。
2. 群聊不得读取文字、语音或图片，不得产生消息入库。
3. 标题证据不完整并判为 `unknown` 时，不得继续搜索。
4. 普通单聊在首屏未找到时，仍能使用短码搜索并进入正确会话。
5. 带短码 private 单聊仍能正常读取和上报。
