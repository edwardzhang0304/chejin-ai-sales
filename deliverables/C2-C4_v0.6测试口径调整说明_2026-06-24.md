# C2-C4 v0.6 测试口径调整说明

结论：本轮按 v0.6 收口后，旧“补偿扫描”方案废弃，不再作为设计、开发、接口、参数或测试依据。测试重点改为第一屏事实采集、状态机定向读取、发送前刷新和召回前预检。

## 一、删除 / 废弃测试项

以下内容不得再作为测试项、验收项或缺陷标准：

| 废弃项 | 测试处理 |
|---|---|
| 多屏滚动补偿扫描 | 删除，不测 |
| 第二屏 / 第三屏滚动扫描 | 删除，不测 |
| sessions compensation | 删除，不测 |
| 滚动页数 | 删除，不测 |
| 滚动到底判断 | 删除，不测 |
| 滚动恢复位置 | 删除，不测 |
| 补偿扫描任务 | 删除，不测 |
| 补偿扫描验收项 | 删除，不测 |

## 三、通过 / 不通过标准

| 结论 | 标准 |
|---|---|
| 通过 | 所有 P0 用例通过；接口、Worker payload、测试脚本和当前有效文档均不再要求补偿扫描；C3/C4 防误发、防误召回闭环通过 |
| 有条件通过 | 主链路通过，但存在非阻塞日志、文案或报告描述残留；需列为 P1 文档整改 |
| 不通过 | 仍出现补偿扫描入口、参数、任务或测试项；C3 发送前不刷新；C4 到期直接创建/发送 follow_up；`watching` 被作为主状态 |
