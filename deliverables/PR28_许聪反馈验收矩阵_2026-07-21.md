## 2. 本次 PR 范围

### 允许进入 PR

- 会话标题和会话类型的通用 OCR 识别。
- 会话物理身份稳定性。
- 已打开正确会话时不重复点击。
- 侧栏数字、时间、预览和增强 OCR 的污染治理。
- 文字、语音、角色与语音父锚点的通用观测输出。
- 旧图片入口的删除或明确退役。
- `fixed-origin` 默认值、显式覆盖和测试的统一。
- Sidecar 新增参数的兼容合同和回归测试。

### 禁止进入 PR

- 车金“只允许 private + 短码”的业务准入策略。
- 新图片上传、Vision 调用或后端图片入库流程。
- Brain、C3、召回或销售状态机。
- Worker 本地增量去重和 outbox。
- Worker 编排层的重复截图优化。
- 车金账号、会话名、车型或用户文本特判。

- 旧图片入口仍可调用，或新 Vision 逻辑被夹带进 PR。

- 许聪审查提出新的 Windows UI 行为风险，且没有既有 V16.104 证据覆盖。
- PR 差异中出现 Brain、C3、召回、后端状态机或图片新流程。
