# AI智能客服售前跟进系统 运营后台设计交付

版本：v0.1

模块：线索管理、销售管理

Figma 文件：https://www.figma.com/design/MMe3OkaLN9UM5jNOGEy9aG

## 1. 交付范围

本设计稿覆盖 P0 运营后台，不覆盖 RPA 自动加微信、AI 自动回复、自动召回、飞书接管、销售登录后台。

包含页面：

- 默认空白工作区
- 线索管理
- 销售管理
- 新增客户弹窗
- 标记无效弹窗
- 恢复有效确认弹窗
- 设计 token 与组件状态说明

## 2. 信息架构

左侧导航：

- 线索管理
- 销售管理
- 操作日志
- 批量导入，P2 预留，置灰
- AI 跟进，后续能力，置灰

右侧默认空白，用户点击有权限的模块后加载对应工作区。

## 3. 线索状态

当前设计只保留三种状态：

- assigned：已分配
- unassigned：未分配
- invalid：无效

不保留 archived / 归档状态。

无效原因建议字段：

```text
invalid_reason = 空号 / 信息错误 / 非目标客户 / 测试数据 / 重复误录 / 其他
invalid_remark = 补充说明
invalid_at = 标记时间
invalid_by = 操作人
```

恢复有效规则：

```text
if sales_id 存在:
  status = assigned
else:
  status = unassigned
```

标记无效时不清空 sales_id。

## 4. 线索管理

主操作：

- 新增客户

列表筛选：

- 搜索：客户名称、手机号后四位、微信、备注
- 状态：全部状态、已分配、未分配、无效
- 销售：全部销售或指定销售

列表字段：

- 客户
- 联系方式
- 状态
- 销售
- 重复
- 备注摘要
- 更新时间
- 操作

操作：

- 查看详情
- 标记无效
- 恢复有效
- 重新分配线索

分页：

- 总条数
- 每页条数
- 上一页 / 页码 / 下一页
- 分页贴列表卡片底部

## 5. 新增客户弹窗

字段：

- 客户名称，必填
- 手机，必填，支持多条
- 微信，选填，支持多条
- 邮箱，选填
- 自定义信息，选填，键值对
- 备注，选填

按钮：

- 取消
- 保存
- 保存并继续新增

重复手机号提示：

- 不创建新线索
- 写入重复录入记录
- 本次备注追加到原线索备注记录
- 提供查看原线索入口

## 6. 销售管理

销售管理作为独立模块，不放在线索管理页面内。

字段：

- 销售姓名
- 启用 / 停用
- 是否参与轮询
- 轮询排序
- 名下线索数量

只有启用且参与轮询的销售，才参与新线索自动分配。

## 8. 前端实现说明

- 推荐将左侧导航和右侧模块内容做权限控制。
- 线索管理和销售管理是同级模块。
- 详情采用右侧抽屉，不跳转页面。
- 标记无效和恢复有效不放入编辑弹窗，作为独立状态操作。
- 重新分配线索按钮只触发自动轮询，不允许手动选择销售。
- 表格手机号默认脱敏，查看完整手机号建议记录操作日志。
