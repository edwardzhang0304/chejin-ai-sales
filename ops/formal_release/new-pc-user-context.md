# 新机引导：Windows 用户与权限

2026-10-19，基于 0.10.6 新机工具的待交付修复；不改变产品版本或已封存安装包。

旧脚本会拒绝所有已提升的进程。内置 Administrator 且关闭 UAC 的桌面，即使普通双击也被拒绝；此时错误发生在文件安装、配置生成和 Worker 启动之前。

新脚本在 Install、Prepare、OpenWorker 共用一个检查入口：必须在交互会话运行，且该会话 Explorer 的所有可核实所有者必须是当前 Windows 用户。无法读取、无 Explorer、多个不同所有者或切换到另一个账号均停止，不选择其他会话，不猜测用户。

- 普通桌面用户继续原流程。
- 系统关闭 UAC，或内置 Administrator 未启用审批模式时，允许同一桌面用户按系统现有权限继续。
- UAC 正常开启时主动以管理员运行，仍提示回到资源管理器普通启动。
- 不修改 UAC、不更改账号/目录权限、不迁移或清空旧数据、不让整个安装器主动提权。
- 原 CopyDll 单独提权路径不变：只对已核验且停止的微信复制固定 DLL，不创建用户配置、不启动 Worker。

文件哈希、微信版本、已有数据保护、端口选择和三项启动参数保持原逻辑。工作微信从桌面快捷方式启动，Worker 从同一用户桌面启动，继承该用户权限。用户事实检查不是新建 Worker 的业务身份绑定，也不替代后续进程/DLL/端口与恢复检查。
